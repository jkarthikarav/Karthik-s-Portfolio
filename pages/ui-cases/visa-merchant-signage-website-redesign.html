The Context

This is a UI design walk through showing how I utilieze my expertise in systems level thinking in UI redesign projects.

Visa has a specialized e-commerce portal where businesses that accept Visa can order official, branded Point-of-Sale (POS) materials such as decals, stickers, and signs (including those for contactless and installment payments).

The focus of this short project is to redesign the website's information architecture and UI design to follow both VISA's brand guidelines and WCAG Accessibility guidelines.
