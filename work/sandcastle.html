How I work

Each tool in my workflow has one job. I decide what gets built, how it works, and whether it meets the requirements.

  • 01 Gather Gemini organizes my ideas into lists, extracts text from images and references, and explains layouts I screenshot.
  • 02 Draft Claude writes code for what I specify, and helps with copy.
  • 03 Build I rework the draft, build locally, and test it.
  • 04 Ship Repos live on GitHub and go out through GitHub Pages.
  • 05 Maintain ChatGPT, connected to GitHub, handles minor changes. Anything new I build locally and push myself.

JAKpot Design System

The Design system behind all my personal websites and products, built with Storybook using React, Vite, and TypeScript.

I defined the visual identity, design tokens, typography scale, spacing rules, component hierarchy, variants, and layout behaviour, then specified each component’s structure, properties, responsive behaviour, and styling.

I learned React and TypeScript with ChatGPT’s help and used it as a coding and debugging partner, translating my decisions into components, CSS, and Storybook documentation.

I reviewed the code and rendered output against my designs, identified defects, and directed the fixes at the component, CSS, and rendering levels. I tested the system against real portfolio case studies, so actual page requirements exposed gaps in component behaviour.
